# Зарядки Хмельницького

Telegram-бот і мінікарта зарядних станцій Хмельницького на Cloudflare Workers.

## Поточна база

- 58 дедуплікованих локацій.
- 50 локацій з актуальними тарифами та конекторами.
- 8 додаткових локацій, підтверджених у Google Maps, але без надійної публічної ціни.
- Знімок даних: 16.09.2026.

Основні технічні дані й тарифи беруться з публічної карти EVBOOST. Google Maps використовується лише для пошуку додаткових точок; записи, що збігаються за координатами або адресою, не дублюються. Тариф у застосунку оператора завжди має пріоритет перед знімком у боті.

## Команди бота

- `/start` — головне меню.
- `/map` — інтерактивна карта.
- `/cheap` — найдешевші станції.
- `/fast` — швидкі станції від 40 кВт.
- `/all` — усі станції з відомою ціною.
- `/nearby` — п’ять найближчих точок за геолокацією.

## Розгортання

```bash
npm install
npm run deploy
```

У Cloudflare мають бути задані секрети `TELEGRAM_BOT_TOKEN` і `TELEGRAM_WEBHOOK_SECRET`. Після першого деплою відкрий `/setup` на домені Worker і введи значення `TELEGRAM_WEBHOOK_SECRET`.

Стан Worker можна перевірити через `/health`, карту — через `/map`.

## Оновлення знімка

Генератор приймає JSON-масиви попередньо нормалізованих даних із `GET /api/web/location/{id}?charging=1` публічної карти EVBOOST і друкує готовий модуль у stdout. Перед генерацією перенеси фактичні конектори з `charging.connectors` у поле `chargers`, зберігши поля `alias`, `power`, `price` і, за наявності, `parkingFee`. Сирі ціни з верхньорівневого `chargers` не використовуй: вони можуть відрізнятися між запитами.

```bash
SNAPSHOT_DATE=2026-09-16 npm run --silent refresh:data -- details-part1.json details-part2.json > stations-data.js
```

Після генерації перевір кількість локацій, синтаксис і `/health`, а потім виконай деплой.
